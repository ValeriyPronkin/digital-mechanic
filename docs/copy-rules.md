# Правила текстов для механика

Что механик видит на экране: интерфейс (`web/src/copy.ts`), строки сервера на карточке, в строке парка и на листе
заявки, README. Тест `tests/test_copy_lint.py` читает блок ниже через `src/service/copy_lint.py` и проверяет эти
тексты. Правило меняется здесь, а не в тесте.

Коротко: вывод первым; без «я» и без «срочно!»; запрет эксплуатации — только словами руководства на этот двигатель
и со страницей; механика не отсылаем к специалисту, главному механику или заводу — называем шаг, который можно
сделать сейчас; «ёлочки», «…», десятичная запятая, неразрывный пробел между числом и единицей.

```slop-lint
# [banned]  regex over whole words, case-insensitive, ё = е  →  what to write instead
#           The lint anchors each pattern so it never starts or ends inside a word.
#           (?-i:…) marks a part where case matters.
#           Not banned, because the manuals use the words literally: «прокачать систему»,
#           «гарантированный натяг», «100 % замене», «лыски под ключ (19 мм)».
# [allow]   names that keep Latin letters inside Russian text, matched exactly
# [units]   units written after a number with a non-breaking space

[banned]
отличн\w+ вопрос|хорош\w+ вопрос                       → the answer
конечно|разумеется|безусловно                         → the answer
давайте (разбер\w+|посмотрим|рассмотрим|начн\w+)      → the answer
надеюсь|обращайтесь|не стесняйтесь|рад\w* помочь      → nothing
(важно|стоит|следует|необходимо) (отметить|учитывать|подчеркнуть|помнить) → the fact itself
обратите внимание                                     → «Учтите:» once, or the fact
к сожалению|увы|упс                                   → what happened and what to do
как (ии|искусственный интеллект|языковая модель)      → what the manual says
я — \w+|я (\w+ ){0,3}(не )?(наш[её]л|найду|создал|проверил|могу|думаю|считаю|рекомендую|читал|назову|ставлю|приведу|оставл)\w*|у меня (нет|есть)|первым ставлю → impersonal or «мы»

(ии|нейросет\w*|алгоритм\w*) (определил|считает|выявил|решил|обнаружил)\w* → по записи, по руководству
умн\w+ (алгоритм|помощник|ассистент)\w*               → the fact
(?<!не )(?<!нельзя )(?<!менее )(?<!более )точно|гарантированно|однозначно|на 100 ?% → вероятно, предварительно
(?<!что )двигатель (полностью )?исправен              → отклонений не найдено
катастрофическ\w*|категорически|критически важно      → what the manual requires, with the page
революционн\w*|инновационн\w*|уникальн\w*|передов\w*  → the fact, in numbers
нового поколения|бесшовн\w*|под ключ(?! \(?\d)|мощн\w+ (инструмент|решени|платформ)\w* → the fact, in numbers
под капотом|на полном ходу|газ в пол|тюнинг\w*        → plain words
мануал\w*|тикет\w*|чанк\w*|промпт\w*|эмбеддинг\w*|галлюцинац\w*|юзер\w*|фич\w*|кейс\w* → руководство, заявка
\bRAG\b|\bLLM\b|\bML\b(?!-)                           → not in the interface
аномали\w*                                            → отклонение
сесси\w*|сеанс\w*                                     → проверка
данн(ый|ая|ое|ого|ой|ом|ому|ую)                       → этот
являет\w*|являют\w*|являться                          → «—»
осуществл\w*|производ\w+ (проверк|поиск|замен)\w*     → the verb itself
в рамках|в целях                                      → для
(?<=[\w,:;] )(?-i:В(ы|ас|ам|ами|аш\w*))               → вы, ваш in lowercase
согласно (документации|руководству)(?! (?-i:[\d«А-Я])) → the designation and the page
транспортн\w+ средств\w*                              → машина
обратитесь к (специалист|мастер|главн\w+ механик|изготовител|дилер)\w* → the step to take now, with its page
решение\W+за главн\w+ механик\w*|решает главн\w+ механик|(оставьте|остается за) главн\w+ механик\w* → the step to take now, with its page
```
