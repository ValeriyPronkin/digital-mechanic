## Причина — воспроизведена на старом коде #155
- Лист растёт по содержимому: у `dialog.sheet` задан только `max-height`.
- Картинка `invisible`, пока не придёт `onLoad`, и до загрузки без высоты.

| Картинка | Старый код | С правкой #158 |
|---|---|---|
| отказ (abort) | лист 176 px: шапка и кнопки ([снимок](evidence/before-abort-390x664-b.png)) | 611 px, пометка и текст страницы ([снимок](evidence/fix-abort-390x664-b.png)) |
| не приходит (hang) | лист 154 px: шапка и кнопки ([снимок](evidence/before-hang-390x664-b.png)) | 611 px, через 8 с текст страницы ([снимок](evidence/fix-hang-390x664-b.png)) |
| опоздала на 9,5 с | — | сначала текст, потом картинка вместо него ([снимок](evidence/fix-late-390x664-after.png)) |

Сервер отдаёт картинку исправно: `57.webp` — 200, `image/webp`, CORS `*`. Почему на iPhone она не пришла или пропал `onLoad`, по стенду не видно. Возможные причины — кэш раньше обработчика или долгий холодный стенд.

Исправление — PR #158:
- лист страницы на телефоне — `92dvh` сразу;
- область листа — `flex-auto`;
- уже загруженная картинка ставится без `onLoad`;
- через 8 с без картинки показывается текст страницы.

**Окончательная проверка — Валерий на iPhone.**
