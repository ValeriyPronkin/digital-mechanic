# Независимая приёмка «Цифрового механика»

Как устроена: отдельная сессия-приёмщик без доступа к коду продукта задаёт вопросы стенду через API — так же, как жюри, — и сверяет ответы с эталонами; каждое число проверяется по PDF руководства. Набор — 40 вопросов: 20 открытых (известны разработке) и 20 скрытых (разработке не показывались), плюс вопрос о противоречии в руководствах. Второй набор — 48 вопросов, составленных вслепую вторым участником команды.

Правило принятия изменений: изменение, меняющее ответы агента, проверяется на скрытой половине; правки, давшие рост только на «знакомых» вопросах, не принимались (пример: +4 на открытых, +0,3 на скрытых при цене ×1,4 — отклонено).
