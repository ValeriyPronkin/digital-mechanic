## Слои себестоимости

1. **Запрос** = модель + эмбеддинг запроса (поиск по смыслу) — таблица выше; только он идёт в строки шаблона организаторов (`make cost-xlsx`), разовое и парк — в его комментарий.
2. **Голос — опция** к запросу: распознавание вопроса (15 с) и синтез короткой фразы (SpeechKit, API дешевле для её длины) — **+0.2666 ₽** на вопрос, округлённо 0,27 ₽ (живой замер — тоже 0,27). Прежние +1,19 ₽ считали синтез всего ответа по API v1, а приложение озвучивает короткую фразу. Альтернатива — без облака: распознавание и синтез речи локально на своём сервере (открытые модели) — 0 ₽ за запрос, затраты — сервер клиента.
3. **Постоянные в месяц на парк** (не в запрос): 325 вопросов в месяц, 0.411 ч работы контейнера (1 vCPU, 1 ГБ), хранилище 0.182 ГБ (индекс и PDF):
   - контейнер (Serverless Containers): **0.0 ₽/мес** в бесплатном уровне, 3.25 ₽/мес без него;
   - хранилище (Object Storage): **0.0 ₽/мес** (первый 1 ГБ бесплатно), 0.35 ₽/мес без бесплатного объёма;
   - простой подготовленных экземпляров контейнера на странице тарифов без цены — не учтён.
