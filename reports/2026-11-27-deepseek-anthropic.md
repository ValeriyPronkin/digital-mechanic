# DeepSeek через Anthropic-совместимый адрес, как у Никиты (ночь 27.11.2026)

Первый пункт плана из `reports/2026-11-27-nikita-gap.md`. Наш агент, поиск и правила — как в `main`. Меняется только способ вызова модели:
- `LLM_API=anthropic` — запрос в формате Anthropic Messages на `https://api.deepseek.com/anthropic/v1/messages`;
- `LLM_EFFORT=low` — как у Никиты; в этом режиме DeepSeek перед ответом рассуждает (блоки `thinking`, проверено пробным запросом);
- к пределу ответа добавлен запас 3000 токенов на рассуждение (`LLM_EFFORT_EXTRA_TOKENS`).

Без этих настроек всё как было: формат OpenAI, `/chat/completions`.

## Вывод

- **Способ вызова модели разрыва с Никитой не объясняет.** Среднее одинаковое — 15,3 во всех трёх вариантах.
- Рассуждение стоит в 2,4 раза дороже и в 1,9 раза медленнее.
- С рассуждением Q16 (перечень одноразовых деталей) и Q23 проходят во всех прогонах, но Q06 («можно ли ехать»: давление 300 кПа) проваливается во всех.
- Под условие PR штурмана («среднее не ниже и цена не хуже ×1,5») подходит только формат без рассуждения: 15,3 = 15,3, цена ×1,37. Пользы от него нет, поэтому PR не открыт. Код — в ветке `s60-deepseek-anthropic`, по умолчанию выключен; если нужен как настройка — PR откроем.
- Остаются кандидаты из отчёта о разнице:
  - цикл, где модель всё выбирает сама;
  - проверка утверждения по своей странице;
  - текст страниц (расшифровка сканов).

## Попутно

Без неё API отвечает 400 «content[].thinking … must be passed back». Первая серия `ds-anth-low` из-за этого упала (16 ошибок из 20) и переделана.
