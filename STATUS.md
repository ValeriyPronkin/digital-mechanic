## Backlog

Формат: **I-NN метка Название** · что сделать · когда готово · как проверить.
Метки: 🏠 только локально в живой сессии · 🌙 годится для ночи (проверка кодом, ядро и сценарий не трогает) · 👤 делает человек · ☁️ отдана облаку → `#<issue>`.
Номера выдаёт агент, новые — только в конец, номер не переиспользуется. Сделанное удаляется отсюда и попадает в «Готово».
Если задач больше ~15 — Backlog целиком переезжает в `BACKLOG.md`; здесь остаётся ссылка. «В работе сейчас», «Ждёт человека», «Сломано» и «Дальше» из STATUS не выносятся никогда.

## Правила ведения

| Событие | Кто | Что обновить |
|---|---|---|
| Начало шага | агент | «В работе сейчас», шапка |
| Зелёный подшаг | агент | «Сделано в шаге»; коммит и push |
| Конец шага | агент | «Готово» (одна строка), убрать из Backlog, «Дальше», метрики с датой, «В работе сейчас» |
| Вопрос человеку | агент | строка в «Ждёт человека» + issue `нужен-человек` + D-N |
| Решение человека | агент | записать в D-N, закрыть issue, **убрать** строку из «Ждёт человека» |
| Поломка | агент | «Сломано» — сразу |
| Начало и конец ночи | ночная сессия | «В работе сейчас»: начало / «ночь закрыта в ЧЧ:ММ», итог, ветки; отчёт — файлом |
| Утренняя приёмка | свежая дневная сессия + человек | сверить заявленное с фактом, «Дальше» |

Правка STATUS — всегда коммит: иначе следующая или облачная сессия её не увидит.

**Чек здоровья — в начале каждой сессии, до работы:**
- [ ] шапка обновлена сегодня, час хакатона верный;
- [ ] «В работе сейчас» совпадает с текущей веткой и последним коммитом;
- [ ] в «Ждёт человека» нет решённого (все упомянутые issues открыты);
- [ ] у метрик есть дата, и она свежая;
- [ ] в Backlog нет сделанных задач и повторов номеров;
- [ ] файл ≤ 120 строк — иначе по порядку: отчёты → файлы, обоснования → D-N, «Готово» → одна строка на этап, решённое из «Ждёт человека» → удалить; если всё равно больше — Backlog → `BACKLOG.md`.

**Чего здесь не должно быть:** отчётов прогонов, обоснований решений, истории «сначала…, потом…», копий текста issue или PR.
