## D-46 · Несколько поставщиков запчастей — файл настроек у каждого · 27.11, день 2 (PR #84; дополняет D-29)

- **Контекст:** Валерий, 27.11: поставщиков несколько, каждый подключается при заключении договора без программиста; раньше `PARTS_SUPPLIER` выбирал один режим.
- **Решение:** `PARTS_SUPPLIERS` — папка или список файлов: `kind` csv|http, имя, сопоставление полей, таймаут, секреты только `env:`. Опрос параллельно с таймаутом на каждого, упавший или медленный — «не ответил». Сортировка: наличие → срок → цена. Обозначение для поиска — только из руководства, иначе по названию с пометкой «по названию, проверьте». `parts_offers` в `/api/v2`. `PARTS_SUPPLIER` работает как раньше. На стенде по умолчанию — «не подключён».
- **Кто:** человек (Валерий) — постановка; агент — устройство.
- **Что проверит:** `tests/test_parts_suppliers.py`, `tests/test_parts_tools.py`.

## D-20 · Качество ответов: план поиска, окно страницы, прямой ответ, причины только с источником · 26.11, день 1

- **Контекст:** приёмщик — 23/40 (страница 77 %, значение 42 %); открытая половина — 9/20 (issue #28). Проверка с телефона: на прямой вопрос — разбор неисправности из карточки и утверждение о причине без источника.
- **Решение:**
  1. План поиска — один короткий вызов модели: язык, перевод, 2–3 запроса словами руководства (синонимы; «можно ли ехать» → аварийное давление масла и запрет эксплуатации; стук → стуки и запрет эксплуатации); код неисправности — не в запрос; ответ — на языке вопроса.
  2. Поиск кодом при любом статусе, кроме сбоя записи и просьбы о заявке; 4 страницы, несколько запросов.
  3. Окно страницы ~1 800 знаков двум лучшим попаданиям; строки со значениями важнее.
  4. Прямой вопрос — прямой ответ; разные значения параметра — все со ссылками и условием; разбор неисправности — только о карточке.
  5. Причины и диагноз без ссылки — код помечает «мнение помощника, не из руководства».
  6. Связь с карточкой — кодом по матрице: страницы ответа вне ячейки «код × двигатель» → строка с работами из ячейки и кнопка к проверке; фразы модели о карточке без ссылки убираются.
- **Почему:** провалы были в поиске и контексте, а не в модели. Цена 0,052 → ≈0,13 ₽ на вопрос — качество важнее (#28), окно — только двум лучшим страницам.
- **Кто:** агент; правила прямого ответа, разных значений, причин с источником и связи с карточкой — человек (проверка с телефона).
