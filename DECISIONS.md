## D-3 · Где хранить PDF и индекс для стенда · 26.11, час ~4 · **ждёт человека**

- **Контекст:** PDF (6 шт., до 99 МБ) и индекс в git и в образ не кладём (issue #3, п. 8). Стенду индекс нужен при старте.
- **Предложение агента:** частный бакет Yandex Object Storage: `manuals/` — PDF, `index/<версия>/` — собранный `.index/` без `cache/extract` (~десятки МБ: fragments.jsonl, vectors.npy, passport.json, кэш эмбеддингов). Индекс собирается локально `make index`, выкладывается одной командой; контейнер при старте скачивает `index/<версия>/` в `INDEX_DIR` (ключ сервисного аккаунта только на чтение — секретом стенда).
- **Варианты:** (а) Object Storage, рекомендация; (б) отдельный том/диск стенда — Serverless Containers его не дают; (в) собирать индекс при старте контейнера — минуты и платный OCR/эмбеддинги на каждый холодный старт.
- **Кто:** агент предлагает, решает человек (issue #6).
- **Нарушает совет из PLAYBOOK:** нет.
- **Что проверит:** смоук стенда — `search` отдаёт страницы руководства после холодного старта.

## D-2 · Индекс руководств: извлечение и поиск · 26.11, час ~4

- **Контекст:** issue #3 — ответы только по руководству двигателя ТС со ссылкой на страницу PDF.
- **Решение:** текст — pypdfium2, таблицы — pdfplumber (PyMuPDF — AGPL, не берём). Номер страницы — только номер PDF с 1; печатный номер и смещение — в паспорте (РЭ ЯМЗ-536: печатный = PDF − 1). Разделы — из страниц оглавления (заданы в `catalog.py`), в РК ЯМЗ-536 оглавления нет — раздел из заголовка модуля данных. Таблицы неисправностей pdfplumber сам не собирает: колонки по вертикальным линиям строки, строки по горизонтальным; разбор с порванными словами отбраковывается, страница остаётся текстом. Поиск: фильтр по двигателю до ранжирования + повторная проверка после; BM25 по леммам (pymorphy3) и эмбеддинги Yandex (doc/query) параллельно, слияние RRF (k=60). Без ключа Yandex — только BM25. Неизвестный двигатель — ошибка, а не поиск по всем.
- **Почему:** лицензии (только MIT/BSD/Apache); фильтр до поиска делает чужую ссылку невозможной по построению. Отброшено: один общий векторный поиск с фильтром после (чужие документы вытесняют свои из топа), разбор таблиц через `extract_tables` (склеивает колонки).
- **Данные во внешний сервис:** в Yandex (OCR, эмбеддинги) уходят только страницы руководств — так поставлено в issue #3; данные ТС и ответы ML не уходят.
- **Кто:** агент.
- **Нарушает совет из PLAYBOOK:** нет.
- **Что проверит:** `scripts/verify_index.py` (20 страниц против PDF, 10 запросов × 4 двигателя, 0 чужих), `tests/test_manuals*.py`.
